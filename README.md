# MCP Server - Servidor de Interoperabilidad e Inteligencia Artificial

Este repositorio implementa un servidor de **Model Context Protocol (MCP)** en Python diseñado bajo una arquitectura modular, extensible y desacoplada. Expone herramientas de cómputo y acceso a fuentes de datos (incluyendo almacenamiento MinIO) a un Agente de IA independiente en un entorno de contenedores independientes conectados por una red externa.
